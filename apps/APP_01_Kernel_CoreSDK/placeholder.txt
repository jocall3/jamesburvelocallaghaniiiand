The Core SDK is not a standalone, deployable application. Instead, its source code resides in the top-level `/sdk` directory of the project repository.

This SDK provides the foundational components, protocols, and interfaces shared by all 74 other applications in the ecosystem. It includes:

-   **Authentication & Identity:** Clients and middleware for the shared auth model.
-   **Protocol Buffers & Data Contracts:** The unified ontology and message schemas.
-   **Event Bus Connectors:** Typed clients for publishing and subscribing to the shared message bus.
-   **Configuration Management:** Standardized configuration loaders.
-   **Logging & Observability:** Common logging formats and tracing instrumentation.
-   **Vendor Adapters:** Interfaces and base implementations for integrating with AI provider APIs.
-   **Core Utilities:** Common data structures, error handling, and helper functions.

This `apps/APP_01_Kernel_CoreSDK` directory exists to ensure the Core SDK is formally tracked as one of the 75 components in the ecosystem manifest. The actual code is consumed as a dependency by the other applications.
